## Documentação Geral para o Pacote example

Esta documentação fornece uma visão geral abrangente do pacote "example", detalhando sua estrutura, funcionalidades e diretrizes de uso. O pacote consiste em dois componentes principais: `Client` e `Service`. 

A classe `Client` atua como uma interface para interagir com o objeto `Service`. Ela recebe um nome como entrada, valida-o, verifica se seu comprimento é par e gera uma mensagem de saudação de acordo. A classe `Service` abriga a lógica para determinar se um número é par e fornece um método para analisar os sinais de três inteiros. 

Este pacote demonstra princípios básicos da programação orientada a objetos, incluindo encapsulamento, abstração e injeção de dependência. Mostra como classes podem interagir entre si para alcançar um objetivo específico.
