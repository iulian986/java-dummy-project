## General Documentation for example package

This documentation provides a comprehensive overview of the `example` package, detailing its structure, functionalities, and usage guidelines. The package encompasses two core components: `Client` and `Service`, which interact to demonstrate a simple interaction pattern. The `Client` class utilizes the `Service` class to generate personalized greetings based on input names and the result of a call to the `Service`'s `isEven` method. The `Service` class itself offers utility methods for basic mathematical operations and string manipulation, including the `isEven` method and a more complex method that prints messages based on the signs of three input integers.

The package aims to illustrate fundamental programming concepts such as object-oriented design, method interaction, and conditional logic. It serves as a starting point for understanding how these concepts can be applied in practical software development scenarios.
