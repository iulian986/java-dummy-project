## General Documentation for example package

This documentation provides a comprehensive overview of the "example" package, detailing its structure, functionalities, and usage guidelines. The package consists of two core components: `Client` and `Service`. 

The `Client` class serves as an interface for interacting with the `Service` object. It takes a name as input, validates it, checks if its length is even, and generates a greeting message accordingly. The `Service` class houses the logic for determining if a number is even and provides a method to analyze the signs of three integers. 

This package demonstrates basic principles of object-oriented programming, including encapsulation, abstraction, and dependency injection. It showcases how classes can interact with each other to achieve a specific goal.
