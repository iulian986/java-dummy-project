## General Documentation for example package

This documentation provides a comprehensive overview of the `example` package. It encompasses the functionalities of the `Client` and `Service` classes, outlining their purpose, interactions, and usage scenarios. The `Client` class demonstrates a simple interaction with a `Service` object, generating personalized greetings based on user input and the results of an `isEven` check performed by the `Service` object. The `Service` class, on the other hand, provides two methods: `isEven` to determine if a given integer is even and `highComplexityMethod` to evaluate the signs of three integers and print messages accordingly. This package serves as a basic example of object-oriented programming concepts in Java, illustrating the principles of class interaction, method invocation, and conditional logic.
