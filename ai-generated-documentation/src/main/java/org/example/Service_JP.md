## Service.java ドキュメント

**1. 概要**

`Service` クラスは、`isEven` と `highComplexityMethod` という2つのメソッドを提供します。

* `isEven` は整数が入力されたときに偶数かどうかを判定します。
* `highComplexityMethod` は3つの整数 (`a`, `b`, `c`) を分析し、その値が正か非正かによって一連のメッセージを出力します。

**2. パッケージ/モジュール名:**

`org.example`

**3. クラス/ファイル名:**

`Service.java`

**4. 詳細なドキュメント**

* **クラス `Service`**

    * **メソッド `isEven(int input)`**
        * **説明:** 与えられた整数 `input` が偶数かどうかを判定します。
        * **パラメータ:**
            * `input`: チェックする整数。
        * **戻り値:**
            * `true`: `input` が偶数の場合。
            * `false`: `input` が奇数の場合。
        * **重要なロジック:**
            * `input` を2で割った余りを計算します (`input % 2`).
            * 余りが0であれば、その数は偶数であり、`true` が返されます。そうでなければ、`false` が返されます。

    * **メソッド `highComplexityMethod(int a, int b, int c)`**
        * **説明:** 3つの整数 (`a`, `b`, `c`) を分析し、その値が正か非正かによってメッセージを出力します。
        * **パラメータ:**
            * `a`: 最初の整数。
            * `b`: 2番目の整数。
            * `c`: 3番目の整数。
        * **戻り値:** なし。
        * **重要なロジック:**
            * `a`, `b`, `c` の値をチェックするためにネストされた `if` 文を使用します。
            * 各整数が正か非正かを示すメッセージを出力します。
            * `a`, `b`, `c` のすべての可能な組み合わせの正負値を処理するようにロジックが構成されています。

**5. 擬似コード**

```
// クラス: Service

// メソッド: isEven(input)
  1. input を2で割った余りを計算する (input % 2)。
  2. 余りが0であれば、true (input は偶数) を返す。
  3. それ以外の場合、false (input は奇数) を返す。

// メソッド: highComplexityMethod(a, b, c)
  1. 'a' の値をチェックする:
     - 'a' が0の場合:
        - 'b' の値をチェックする:
           - 'b' が正の場合:
              - 'c' の値をチェックする:
                 - 'c' が正の場合: "c は正" を出力する。
                 - それ以外の場合: "c は非正" を出力する。
           - それ以外の場合: "b は非正" を出力する。
     - 'a' が0未満の場合:
        - 'b' の値をチェックする:
           - 'b' が正の場合:
              - 'c' の値をチェックする:
                 - 'c' が正の場合: "c は正" を出力する。
                 - それ以外の場合: "c は非正" を出力する。
           - それ以外の場合: "b は非正" を出力する。
     - それ以外の場合: "a は非正" を出力する。



```
