## Service.java ドキュメント

**1. 概要**

`Service` クラスは、`isEven` と `highComplexityMethod` という2つのメソッドを提供しています。

* `isEven` は、与えられた整数が偶数かどうかを判定します。
* `highComplexityMethod` は、3つの整数 (`a`, `b`, `c`) を分析し、その値が正または非正であるかによって、一連のメッセージを出力します。

**2. パッケージ/モジュール名:**

`org.example`

**3. クラス/ファイル名:**

`Service.java`

**4. 詳細なドキュメント**

   - **メソッド `isEven(int input)`**
     - **説明:** 提供された整数 `input` が偶数かどうかを判定します。
     - **パラメータ:**
       - `input`: チェックする整数。
     - **戻り値:**
       - `true`: `input` が偶数の場合。
       - `false`: `input` が奇数の場合。
     - **重要なロジック:**
       - `input` を2で割った余りを計算する剰余演算子 (`%`) を使用します。余りが0であれば、その数は偶数であり、メソッドは `true` を返します。そうでなければ、`false` を返します。

   - **メソッド `highComplexityMethod(int a, int b, int c)`**
     - **説明:** 3つの整数 (`a`, `b`, `c`) を分析し、その値が正または非正であるかによって、メッセージを出力します。
     - **パラメータ:**
       - `a`: 最初の整数。
       - `b`: 2番目の整数。
       - `c`: 3番目の整数。
     - **戻り値:** なし。
     - **重要なロジック:**
       - `a`, `b`, `c` の値をチェックするために、一連のネストされた `if` 文を使用します。
       - 各整数が正または非正であるかどうかを示すメッセージを出力します。
       - ロジックは、`a`, `b`, `c` のすべての可能な組み合わせの正および非正値を処理するように構成されています。

**5. プセウドコード**

```
// クラス: Service

// メソッド: isEven(input)
  1. input を2で割った余りを計算する。
  2. 余りが0であれば、true を返す。
  3. それ以外の場合、false を返す。

// メソッド: highComplexityMethod(a, b, c)
  1. 'a' の値をチェックする:
    - 'a' が0の場合:
      - 'b' の値をチェックする:
        - 'b' が正の場合:
          - 'c' の値をチェックする:
            - 'c' が正であれば、"c is positive" を出力する。
            - それ以外の場合、"c is non-positive" を出力する。
        - それ以外の場合、"b is non-positive" を出力する。
    - 'a' が0未満の場合:
      - 'b' の値をチェックする:
        - 'b' が正の場合:
          - 'c' の値をチェックする:
            - 'c' が正であれば、"c is positive" を出力する。
            - それ以外の場合、"c is non-positive" を出力する。
        - それ以外の場合、"b is non-positive" を出力する。
    - それ以外の場合、"a is non-positive" を出力する。



```
